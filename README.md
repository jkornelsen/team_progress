# Team Progress Kit

Produce, interact, and explore, driven by storytelling and chance. Model ideas using descriptive text as building blocks.

**🎲[Play Online](https://teamprogress.pythonanywhere.com/)**

> Hosted on free tier, so it may be slower for multiple simultaneous players.

## Overview

A good place to start is the pre-built quest **Bacon for Dinner.** The full idler **Rays** is also worth highlighting.

The original idea behind this game was to be an *incremental-plus,* with tabletop mechanics to provide the flexibility other idlers lack. Like, employees from a rival factory might suddenly attack with staplers.

## Right for you?

You'll probably “get” this game if you have done any of these:

* Enjoyed *A Dark Room* and *Universal Paperclips* but wished you could change things
* Used a spreadsheet to min/max *Leaf Blower Revolution*
* Set up your own text documents to play *D&D* on the computer
* Used *Iron Journal*
* Played *UnReal World*

## Suggestions for Playing

- With the **Dating** scenario, track the narrative in a separate markdown document, optionally enhanced by AI.

- Anytime the story calls for a value that isn't handled automatically, go ahead and make the change in settings—don't worry that you might be bypassing the “official” game.

- Scenarios such as **Dungeon Crawl** can support multiple players effectively, where the Gamemaster controls the configuration. Use Discord to write the narrative and communicate.
